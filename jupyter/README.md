# Harshu AI OS notebooks

Use `learning_path/` in numeric order. These notebooks are the curated reference
set; older experiments are preserved unchanged under the local `legacy/` folder.

| Order | Notebook | Main purpose |
|---|---|---|
| 1 | `01_python_foundations_and_structure.ipynb` | Functions, modules, OOP, errors, files, data structures, and Big-O |
| 2 | `02_llm_routing_and_reliability.ipynb` | Route dictionaries, provider neutrality, retries, and error boundaries |
| 3 | `03_embeddings_chroma_and_rag.ipynb` | Chunking, embeddings, vector distance, retrieval, grounding, and citations |
| 4 | `04_langchain_testing_and_api_flow.ipynb` | Prompt/model/parser chains, fake models, testing, and the complete API flow |

## How to use each notebook

1. Read the three-arrow flow.
2. Run the worked example.
3. Change the marked input.
4. Complete the small `YOUR TURN` task.
5. Explain the result in three sentences.

The notebooks use synthetic examples and fake model responses by default. They
do not print secrets or require paid provider calls.
